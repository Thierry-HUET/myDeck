## Des présentations type PowerPoint, en Markdown

*Thierry HUET — APERTO-NOTA*

## Le principe

- Un fichier **`deck.md`** contient les slides
- Une ligne `---` sépare deux slides
- Un fichier **`style.css`** définit le thème

---

## Mise en forme

### Titres, listes, citations, tableaux…

- **Gras**, *italique*, `code`
- [Liens](https://github.com/Thierry-HUET/myDesk)

## Raccourcis

| Touche | Action |
|--------|--------|
| `←` / `→` | Slide précédente / suivante |
| `F` | Plein écran |
| `O` | Vue d'ensemble |
| `Ctrl+P` | Impression (1 slide / page) |
